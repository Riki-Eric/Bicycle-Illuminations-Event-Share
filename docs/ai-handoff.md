AIがリポジトリを読める場合は、最初に [AGENTS.md](../AGENTS.md) と[資料の索引](README.md)を読ませます。配線の相談では、機器名・基板の版・スケッチ番号・端子・見る面を添えると、対象を絞れます。

```text
この公開リポジトリの AGENTS.md と docs/README.md を読んでください。
対象機器・箱ID・基板の版・スケッチ番号は以下のとおりです。
期待した動作、現物で起きたこと、取得したログを照合してください。
案内の根拠になるソースや配線図のパスを示し、
ソースから分かること、実測で分かること、現地で確認する項目を明示してください。

機器・箱ID・A/B：
基板の版・ESPまたはNanoの機種：
書き込んだスケッチ番号：
端子と見ている面：
操作・設定・期待した動作：
実際の動作と共有できるログ：
```

## 回転数ログを渡す場合

45番の `START`〜`END`、A/Bごとの伝達比、測定したギア、試走の途中で止めた時刻、目標とする演出時間を添えます。43番の `show` と39番の `config tree_turns` があれば、現行目標との比較ができます。

ログや写真を渡す前に、Wi-Fiの接続情報、一時URL、個人を識別できる情報を取り除きます。回転数の記録にはA/Bの機材ラベルを使います。

関連資料は[回転数と演出の調整](configuration.md)と[検証状況](validation.md)です。
