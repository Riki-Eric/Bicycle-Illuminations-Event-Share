# 回転数と演出の調整

## 円板のパルスとペダルRPM

使用する円板は1周に6スリットあります。1スリットの立ち下がりを1パルスとして数えるので、円板回転数はパルス数÷6です。ペダル1回転あたりに円板が何回転するかをA/Bそれぞれで測り、円板RPMをその値で割るとペダルRPMになります。

80 rpmは試走前のペダル回転の想定値です。45番で測る円板RPMと比較するには伝達比が必要です。[1分計測](testing.md#回転数を60秒計測する)ではA/Bを本番と同じギアや取り付け状態で測ります。

43番の通常目標を変更する場合は39番を停止し、43番の `show main` で対象を確認します。目標をパルスで設定するコマンドは `goal <Aパルス> <Bパルス>`。変更前後の `show` と `config` を記録します。Sitesの走行中倍率は公演中の調整です。

## ツリー

- 39番の `tree_turns` は両翼が達成した後に積算する両者の**円板回転数の合計**。ソースの初期値は360。A/Bの実測円板RPMの合計が160なら、一定速度で360÷160＝2.25分。試走の見積もりであり、実演の所要時間は回転数で変わる。
- 各段を点けるしきい値は40番の `step_pct`。既定10では下から **20% → 38% → 54% → 68% → 80% → 91% → 100%**。同じ速さで漕ぐ区間では、上に行くほど次の段までの時間が短くなる。上下の40番を同じ設定で照合する。
- 翼とツリーの時間をそろえるには、まず翼の両側が達成する時刻をログから見積もり、その後に漕ぎ続けるときの円板RPMでツリーの合計目標を計算する。試走した条件と保存値を並べて記録する。
