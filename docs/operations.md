# 設営・本番操作

## 準備日の確認

1. 箱に機器名・箱ID・A/Bを貼る。自転車はどちらもアップライトで、B2のJ4をA、J5をBへ割り当てる。
2. 全電源を切り、[現行の基板仕様と配線図](../wiring/README.md)で端子と電圧を照合する。B2の制御5 V・軌跡5 V・車体12 V、A3の制御5 V・照明24 Vを行き先のラベルで区別する。翼予備機は12 V負荷をユニバーサル基板やNanoに通さない。
3. 各機器に本番スケッチを書き込む。負荷電源を入れる前に定格、極性、保護、外部給電とUSBを併用できる条件を確認する。
4. 39番を`OFF`にし、各機器の`status`で箱IDと異常表示を確認する。[シリアルコマンド](serial.md)の位置表示を1系統ずつ実行し、箱・端子・実際に光った場所を照合する。
5. 回転センサーは片側ずつ円板を一周させて6パルス増えることを確認する。各車体の表示器でA/Bの割当を確認する。調整に使う記録は[試験と合格条件](testing.md)に沿って残す。
6. 人物照明J6は初期設定で消灯。軌跡LEDは通行の邪魔にならない位置へ設置し、目印表示でボタン側から自転車側への向きを確認する。

## 会場の通信確認

- 39番を会場ルーターにつなぐときは2.4 GHz・チャンネル6を確認する。Sites送信状態は39番のUSBシリアルで`site status`。必要な接続設定は現地機材担当から受け取る。
- ルーター経由が使えないときは39番のESPへスマホを接続し、起動時に案内されるローカルページの`/view`または`/send`を前面に開く。Sitesの表示が更新されることを確認する。スマホとESPの接続だけを先に試せる[47番](../tests/47_wifi_access_point/)もある。
- スタッフ端末は停止中に39番へ`site staff`を送り、表示された一時リンクを60秒以内に開く。接続情報や一時リンクは作業場所で扱う。
- `status`で39番から見た機器の受信経過と重複IDを確認する。各機器でも指示を受けた状態を確認し、照明の実動作は現地で見る。

## 本番と予備開始

担当者が全機器の準備と通路を確認し、39番を`arm`して市長ボタン操作を待ちます。市長が押した後は、軌跡の開始を現地で確認してください。

- 市長が押したのに軌跡が始まらないときは、担当者が実物と現在の進行を確認してSitesの予備開始を使う。二段階で確認し、誤操作に気づいたら約5秒の取消時間内に取り消す。
- 途中の照明が始まらないときは、未点灯を目視し、現在の進行表示を見て対象段階の予備操作を行う。受信経過や指令が更新された後は、光った場所を担当者に確認する。
- シリアルの`stop`で消灯する。39番の現地ボタンは演出・試験中なら停止、開演待ち中は予備開始に使う。通信障害の復帰後は各機器の消灯を確認し、再開する公演だけを改めて待機にする。
- 終演後の保持状態から`steady`で定常運転へ切り替える。試験点灯と本番開始を扱う担当者は開始前に声をかけ、試験終了時にOFFを確認する。
