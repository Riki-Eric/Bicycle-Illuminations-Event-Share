# 機器と進行

## 信号と機器の関係

| 起点 | 受ける機器と役割 |
| --- | --- |
| 市長ボタンの無電圧接点 | 42番のボタン台が入力を読み、39番に開始を知らせる。 |
| 自転車A/Bの円板センサー | 43番の翼制御が計数。A/BのRPMを27番の各表示器へ送り、進捗と円板パルスを39番へ報告する。 |
| 39番の自転車側制御 | 進行を管理し、軌跡J3と車体J4・J5を駆動。翼・ツリー・ドレープ・外周には進行の合図を出す。 |
| 43番のXIAO版 | 翼の予備機では44番のNanoが信号を受信し、翼LEDの実出力を担当する。 |
| 40・41番の24 V制御 | 40番はツリー上下、41番は外周の各箱。箱IDに応じた照明を出力する。 |
| 38番のドレープ | A/Bが各自のテープを駆動。39番が両側の完了報告を受けて保持へ移る。 |

[39番の状態遷移](../production/39_bike_opening_show/src/OpeningShow/ShowState.h)と[配線図](../wiring/README.md)を合わせて参照してください。

## 本披露の順序

1. `ARMED`で待機し、市長ボタンの操作を受けて`TRAIL`へ。軌跡の演出始点はボタン側、到着点は自転車側。
2. `RIDE`でA/Bの車体照明をRPMに応じて調光し、翼をそれぞれ蓄積する。両翼が100%になると`TREE CHARGE`へ。
3. `TREE CHARGE`開始後の両者の円板回転を合計する。ツリーは下から、進捗が各段のしきい値に達するごとに点く。
4. ツリーが100%に達すると`WHITE`、続いて`SPARKLE`へ。その後`DRAPE`でドレープを流す。39番の冒頭コメントには「同時に」とあるが、配布版の実行経路には白ときらめきの段階がある。
5. 両ドレープ完了で`HOLD`へ進み、外周も点灯する。終演後は担当者が`STEADY`に切り替える。短縮披露を選ぶと両翼達成後の経路が変わる。

## 会場内の通信とSites

照明機器の合図と報告はチャンネル6のESP-NOWを使う。公開版のSitesとの送受信は[39番の窓口](../production/39_bike_opening_show/DirectSite.h)を経由する。ルーター経由とスマホ中継のセットアップは[設営・本番操作](operations.md)を参照。

39番の受信時刻と各箱の状態表示で、準備・指示の受信・出力指令を切り分ける。次の段階への移行は39番で確認する。27番はRPM受信器なので、各表示器の受信状況は自身のUSBシリアルで確認する。全点灯の結果は各機器を目視する。
