# 試験と合格条件

配線を替える前に全電源を切り、[給電と配線図](../wiring/README.md)を確認します。特に28番は起動後に順送りを始めるため、出力を接続したまま書き込む前に確認してください。

| --- | --- | --- |
| [04](../tests/04_led_basic/) | classic Nanoと翼用12 V LED | `1`〜`4`で赤・緑・青・白、`c`で流れる方向、`i`でA/Bを目視。 `0`で消灯 |
| [25](../tests/25_tree_light_pwm/) | DevKitCと外付け回路で24 V照明1本 | 金（GPIO25）と白（GPIO26）を分けて確認。製作したA3のT端子は40・41番で確認 |
| [26](../tests/26_wing_rpm_sender/) | DevKitCまたはXIAOの回転入力とRPM送信 | `count zero`後に片側の円板を1周し、回した側が6増える。無線は27番の実受信で確認 |
| [28](../tests/28_rider_bars_test/) | DevKitCの8灯表示 | 起動後にD1→D8の順送り、伸縮・全点灯・消灯。緑2・黄3・赤3、消灯と欠灯の有無を目視 |

46と47は照明を駆動しません。46の往復はテザリング上の試験用UDPです。本番のESP-NOWと出力は本番スケッチへ戻した後に確認します。

## 回転数を60秒計測する

1. 翼の予備機のNanoに45番を書き込む。負荷を切り、FC-33は既存の3.3 V給電を確認したうえで、OUTをA＝D2・B＝D3へ仮接続し、GNDを共通にする。
2. 115200 bps・改行ありで `start`。1秒ごとに円板のパルスとRPMが出る。試走前に片側ずつ既知の回転数を与え、配線と6パルス/周を確認する。
3. 本番と同じ機材・ギアで漕ぎ、`START`から`END,complete`までを保存する。 `a_interval` と `b_interval`は測定区間のパルス数、`a_total` と `b_total`は試験開始後の累計。 `a_shaft_rpm` と `b_shaft_rpm`は円板軸のRPM。
4. A/Bごとに円板とペダルの伝達比、漕ぎ始めの時刻、定常の区間、途切れがあればその時刻を添える。45番ではLEDの進捗を計測しない。必要なら本番リハーサルで43番と39番の `status` を別に記録し、時間と照合する。
5. 計測後は仮配線を外し、使用するD8/A0設定でNanoに44番を書き戻す。43番の目印表示で通信と翼LEDを確認する。

## 残す結果

各試験で **箱ID／A・B／基板とスケッチ番号／設定／端子／期待した動作／現物で起きたこと／合否** を記録します。たとえば「ツリー下のID 1、T2で `test 2`。実際に下から2段目が電球色→白になり、自動で消灯」と記録すると担当者とAIが照合できます。
