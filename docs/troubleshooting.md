# 症状別の切り分け

| 症状 | 最初に確認すること |
| --- | --- |
| `src/...` のヘッダーが見つからずコンパイルできない | ZIPをすべて展開したか、同名のフォルダー内に `.ino` と `src/` があるかを確認。[ボードと依存関係](firmware.md#ボードと依存関係) |
| USBシリアルに表示が出ない | 対象機器とCOMポート、115200 bps、改行設定を確認。XIAOはUSB CDC On BootがEnabledかを確認 |
| Aを回したのにBの数字が増える | LED出力を止め、43番または26番で `count zero` → Aの円板を1周 → `count`。増えた入力のXHとA/Bの配線を照合 |
| 円板1周で6パルスにならない | XHの3.3 V・OUT・GND、円板の位置、センサーとの間隔を確認。少数回で再現し、計数が飛ぶ回転域を記録 |
| 27番の表示だけが反応しない | 27番の `role` と `status`、43番または26番のRPMを確認。27番の `test` でLED単体の反応を見る |
| 翼予備機が光らない | 43番と44番のD8/A0設定、信号GND、44番の受信・エラー件数を確認。43番の `mark` と翼LED用電源・DINの向きを照合 |
| ツリーが途中の段から光る | 上下の箱ID、`map`、`reverse`、使用端子を確認し、個別の `test` を使う。 `TREE CHARGE` の進捗が最初の段のしきい値まで達したかも見る |
| 39番で同じ役割が重複する | ドレープ・ツリー・外周の各箱に固有IDを割り当てる。外周の箱数は39番の `plazas` を照合 |
| Sitesの表示が更新されない | 39番の `site status` と会場ルーターを確認。スマホ中継ならESPに接続してローカル送信用ページを前面に開いた状態で再確認 |
| 表示は点灯中だが光っていない | 出力指令と現物を区別する。端子・負荷電源・GNDの配線を停止して照合し、該当機器の目印または個別試験で確認 |

再試験の前に、どの箱・端子・スケッチを見ているかを合わせます。出力を伴う操作は[設営・本番操作](operations.md)の停止確認後に行ってください。
