# 検証状況

## 公開配布版で確認したこと

- 配布した本番8本・単体試験8本をArduino CLIでコンパイルし、同梱のソースとライブラリでビルドできることを確認した。使用コアはesp32 3.3.12とArduino AVR Boards 1.8.8。
- 26・43・46・47番はDevKitC V4向けとXIAO ESP32C3向けのビルドを確認した。43番のXIAOは既定のD8構成。44番はclassic Nano向けにD8とA0を確認した。43番XIAOの明示的なA0設定については、この配布時のコンパイル記録に含まれていない。
- 配線図15点を配布対象として確認した。接続判断には[図の基板リビジョンと現物](../wiring/README.md)を照合する。
- [シリアル操作](serial.md)と[演出順序](system.md)は現行の配布ソースを参照する。冒頭コメントと実行順の差は機器と進行の資料に記載した。

## 現地で残す証拠

| 確認 | 合格とする記録 |
| --- | --- |
| 市長ボタン台のXIAO配線 | 接点と状態LEDの端子を導通で特定し、42番のGPIOを照合。押し・離し、照光、待機後の開始を現物とログで確認 |
| 回転測定・翼のA/B | A/Bの6パルス/周、ペダルとの伝達比、60秒の試走結果 |
| 各照明の実出力 | 箱ID、端子、色、方向と実際に点灯した場所。給電と末端の状態も確認 |
| 無線と予備開始 | 機器別の指示受信・進行と実点灯、Sites表示、誤操作の取消、通信断後の消灯 |
| 演出と所要時間 | 軌跡→両翼→ツリー→ドレープ→外周の実進行、両翼とツリーにかかった時間、定常運転への切替 |

公開資料には上表の現地試験の合格記録を掲載していません。[試験と合格条件](testing.md)を使って、回路・通信・光り方を個別に記録してください。
